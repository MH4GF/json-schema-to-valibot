# Project Brief: JSON Schema to Valibot Converter

## Core Purpose
Create a tool that converts JSON Schema definitions to Valibot schema definitions, making it easier for developers to migrate from JSON Schema to Valibot validation.

## Project Components
1. Core Package (`json-schema-to-valibot`)
   - CLI tool for schema conversion
   - Parser implementation
   - Test suite with fixtures

2. Website Package
   - Web interface for schema conversion
   - Interactive playground
   - Documentation and examples

## Key Requirements
- Accurate conversion of JSON Schema to Valibot schemas
- Support for complex schema features (enums, arrays, objects, etc.)
- Both CLI and web-based interfaces
- Comprehensive test coverage
- Developer-friendly documentation

## Success Criteria
- Reliable schema conversion
- Easy-to-use interfaces (CLI and web)
- Comprehensive documentation
- High test coverage
- Performance optimization for large schemas
