# Product Context

## Problem Statement
Developers migrating from JSON Schema to Valibot face the challenge of manually converting their schema definitions. This process is time-consuming and error-prone, especially for large or complex schemas.

## Solution
Provide an automated tool that converts JSON Schema definitions to equivalent Valibot schemas, available through both CLI and web interfaces.

## User Experience Goals
### CLI Interface
- Simple command-line usage
- Clear error messages
- Support for file input/output
- Configurable output options
- Depth control for complex schemas
- Intuitive shorthand flags
- Type generation capabilities

### Web Interface
- Interactive schema conversion
- Real-time preview
- Copy-to-clipboard functionality
- Modern, responsive design

## Target Users
- Developers migrating from JSON Schema to Valibot
- Teams adopting Valibot in existing projects
- Developers exploring Valibot as an alternative

## Key Benefits
1. Time Savings
   - Automated conversion process
   - Reduced manual effort
   - Faster migration path

2. Accuracy & Control
   - Consistent conversion results
   - Validated output schemas
   - Preserved schema semantics
   - Configurable schema depth
   - Type-safe output generation

3. Accessibility
   - Multiple interface options
   - No installation required for web version
   - Clear documentation and examples
